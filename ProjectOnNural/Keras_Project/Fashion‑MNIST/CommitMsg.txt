Fashion‑MNIST is a dataset of 70,000 grayscale images of clothing items, created by 
Zalando Research as a more challenging replacement for the classic MNIST digit 
dataset.
It is widely used for:
- benchmarking machine learning models
- testing deep learning architectures
- experimenting with image classification

Dataset Compositions:

Split         | Samples       | Purpose         
--------------|---------------|------------------
Training set  | 60,000 images | Model training   
Test set      | 10,000 images | Model evaluation 

 Image Properties
- Size: 28 × 28 pixels
- Color: Grayscale (1 channel)
- Format: NumPy arrays when loaded via Keras
- Pixel values: 0–255 (usually normalized to 0–1)
Each image contains a single centered clothing item on a plain background.

Labels (10 Classes)
Fashion‑MNIST has 10 categories, each represented by an integer label:
Label | Class Name  
------|----------------
0     | T-shirt/top  
1     | Trouser  
2     | Pullover  
3     | Dress  
4     | Coat  
5     | Sandal  
6     | Shirt  
7     | Sneaker  
8     | Bag  
9     | Ankle boot

Why Fashion‑MNIST is Popular
- Harder than MNIST → better benchmark for real‑world performance
- Small and fast → ideal for quick experiments
- Drop‑in replacement for MNIST → same shape, same format
- No preprocessing required → clean, standardized images

Typical Use Cases
- CNN training and comparison
- Testing optimizers, regularization, and architectures
- Feature extraction and dimensionality reduction (PCA, t‑SNE)
- Benchmarking classical ML models vs deep learning
